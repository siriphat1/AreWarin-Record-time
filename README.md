# AreWarin Tutor OS v2.2 — Student Calendar & Parent Reports

ต่อยอดจาก v2.1 โดยไม่เปลี่ยนโครงสร้าง Google Sheets และรักษา Billing / Courses / Attendance / Ledger เดิมทั้งหมด

## การเปลี่ยนแปลง

1. **Student Personal Calendar**: ใน Students & Courses > เปิดโปรไฟล์ แสดงปฏิทินรายเดือนแนว Google Calendar (จันทร์–อาทิตย์), เลือกเดือนและคลิกวันได้; ดึงทั้งเรียนเดี่ยว เรียนกลุ่ม (สมาชิกปัจจุบัน) และคาบที่บันทึกจริงจากข้อมูลกลาง Schedules/Sessions/Attendance. หากคาบที่นัดไว้กับคาบที่บันทึกจริงเป็นคาบเดียวกัน ระบบจะแสดงคาบที่บันทึกแล้วแทน ไม่แสดงซ้ำ
2. **Remove duplicate history table from profile**: เอาตาราง “ประวัติการเรียนตามวันที่” ที่ซ้ำกับ Learning History ออกจาก Student Profile. ยังเก็บประวัติใน Google Sheets ครบ และให้ไปที่ Learning History เพื่อดู/แก้ไข/ยกเลิกหรือคืนชั่วโมง
3. **Parent/Guardian Monthly Report**: ใน Reports และจากโปรไฟล์นักเรียน กรองนักเรียน, เดือน, คอร์ส / รอบเรียน (รวม archived), แสดงวันที่เรียน เวลา ติวเตอร์ เข้าร่วมจริง ชั่วโมงที่บันทึก และสถานะค่าคาบ
4. **Export**: ดาวน์โหลด CSV (UTF-8 BOM สำหรับ Excel) หรือกด พิมพ์ / บันทึก PDF เพื่อเปิดหน้ารายงานพิมพ์ของเบราว์เซอร์ จากนั้นเลือก Save as PDF. ไม่มีการส่งข้อมูลไปยังบริการ PDF ภายนอก

## วิธีติดตั้งจาก v2.1

1. สำรอง Google Sheets และไฟล์เว็บไซต์เดิม
2. อัปโหลด `index.html`, `assets/app.js`, `assets/style.css` รุ่นนี้แทนของเดิมบน GitHub Pages
3. **เก็บ `config.js` เดิม** ไว้ ไม่คัดลอกไฟล์ตัวอย่างจาก ZIP ไปทับค่าจริง
4. เปิดเว็บไซต์แบบ Hard Refresh (`Ctrl+Shift+R`)
5. เปิดโปรไฟล์นักเรียน → ปฏิทิน และ Reports → รายงานรายบุคคล เพื่อลองกรอง/ส่งออก

**ไม่ต้องรัน `setupTutorOS()` ใหม่** เพราะไม่ได้เปลี่ยนชื่อชีตหรือเพิ่มคอลัมน์

## นิยามข้อมูลในรายงาน

- รวมเฉพาะ Attendance สถานะ `approved` และ Session สถานะ `approved`
- ไม่รวมรายการยกเลิกหรือ Pending เก่า
- เวลาเข้าร่วมจริง (`actual_minutes`) อาจไม่เท่ากับเวลาที่บันทึก/ตัด (`deduct_minutes`)
- รายงานคอร์สรายชั่วโมงแสดงค่าคาบและสถานะ; ไม่ถือว่ายอดค้างชำระเป็นยอดที่จ่ายแล้ว
- ไม่รวมชั่วโมงสอนของนักเรียนคนอื่นในกลุ่มเข้ากับนักเรียนที่เลือก
- คอร์สเก่าที่ archived ยังค้นและกรองดูได้

## ข้อจำกัด

- ปฏิทินยังไม่ใช่ระบบ Google Calendar Sync: เป็นหน้าปฏิทินใน Tutor OS ที่ดึงจากตารางเรียนและ Attendance ของระบบเอง
- การแก้ตารางเรียนทำใน Class Schedule; การแก้ประวัติจริงทำใน Learning History (ไม่แยกฐานข้อมูลซ้ำ)
- โปรแกรมยังใช้ Google Sheets API ผ่านเบราว์เซอร์เช่น v2.1 และยังไม่ได้ทดสอบกับ Google Sheets จริงของผู้ใช้
- ก่อนส่งรายงานผู้ปกครอง ควรตรวจว่ารายชื่อนักเรียน เดือน และคอร์สถูกต้อง และเก็บไฟล์ที่ดาวน์โหลดไว้ในพื้นที่ปลอดภัย
- การทดสอบใน Chromium ใช้ข้อมูลจำลองเท่านั้น
