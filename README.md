# AreWarin Tutor OS v2.0.1 — Date & Attendance History Fix

เวอร์ชันแก้ข้อบกพร่องจาก v2.0 **โดยไม่เปลี่ยน Google Sheets schema หรือข้อมูลเดิม**

## สิ่งที่แก้ไข

1. หน้า Import → Student & Meet Matching **ไม่แสดงช่องแก้วันที่ทุกไฟล์ซ้ำ** อีกแล้วเมื่อระบบตรวจพบวันที่ถูกต้องจาก Excel/ชื่อไฟล์ วันที่ของแต่ละไฟล์ยังอยู่ใน **Imported Class Summary** ด้านบน
2. ถ้าต้องการแก้วันที่เฉพาะไฟล์ กดลิงก์ **แก้วันที่** ใต้วันที่ของไฟล์นั้นในตาราง Imported Class Summary แล้วกรอกวันที่ ระบบจะอัปเดตเฉพาะไฟล์นั้น ไม่เปลี่ยนอีก 16 ไฟล์
3. หากไม่พบวันที่ หรือวันที่ใน Excel ขัดแย้งกับชื่อไฟล์ ช่องแก้ไขวันที่จะปรากฏทันทีเพื่อให้ตรวจสอบก่อนบันทึก
4. หน้า **Session Details** เน้นวันที่ของคาบที่เปิดอยู่และเพิ่มคอลัมน์วันที่ในตารางผู้เข้าร่วม โดยย้ำว่าหน้านี้เป็นคาบเดียวเท่านั้น ไม่ได้รวมหลายไฟล์เป็นคาบเดียว
5. เพิ่มแถบ **“ดูคาบเรียนวันอื่นของนักเรียนในคาบนี้”** กดขยายเพื่อดูรายการย้อนหลังจากคาบอื่นที่อยู่ในฐานข้อมูล (แยกวันที่ เวลา นักเรียน และเวลาหัก) พร้อมปุ่มเปิดคาบต้นทาง
6. กดชื่อนักเรียนใต้ Session Details เพื่อเปิด **Learning History** ที่กรองนักเรียนคนเดียวกันและดูทุกวันได้
7. แก้บั๊กตัวกรองคอร์สใน Learning History ซึ่งก่อนหน้านี้มีช่องกรองแต่ยังไม่ได้ใช้กับรายการจริง
8. อัปเดตหมายเลขเวอร์ชันและ query string ของ CSS/JS เพื่อให้ GitHub Pages โหลดโค้ดใหม่โดยไม่ติด cache เก่า

## วิธีอัปเดตจาก v2.0

1. สำรอง Google Sheets และไฟล์เว็บก่อน
2. นำ `index.html`, `assets/app.js`, `assets/style.css` จาก ZIP ขึ้น GitHub Pages แทนไฟล์เดิม (แทนทั้งสามไฟล์)
3. **อย่าแทนที่ `config.js` เดิม** เพราะมีค่าการเชื่อมต่อ Google OAuth และ Spreadsheet ID ที่ตั้งไว้แล้ว
4. Refresh แบบ `Ctrl+Shift+R` แล้วเปิด Import → ตรวจตารางวันเรียน; หน้าจับคู่ชื่อจะไม่มีช่องวันที่เมื่ออ่านวันที่ได้ถูกต้อง
5. เปิด Learning History → เลือกคาบวันที่หนึ่ง → กดดูคาบอื่นของนักเรียนในคาบนั้น

**ไม่ต้องสร้าง Google Sheets ใหม่ และไม่ต้องรัน Setup.gs** เมื่อมาจากฐานข้อมูล v2.0 ที่ใช้งานได้อยู่แล้ว

## ขอบเขตการตรวจสอบ

- ผ่าน `node --check` และ regression scripts 6 ชุด
- ผ่าน browser test `tests/v201-dates-attendance-browser.test.py` (หลายวันที่, ช่องแก้วันที่เมื่อจำเป็น, แก้ทีละไฟล์, วันเรียนอื่นใน Session Details, ลิงก์กรองประวัติ, ตัวกรองคอร์ส)
- ยังไม่ทดสอบบน Google Sheets จริงของผู้ใช้; เมื่ออัปเดตแล้วให้ตรวจว่ารายการที่เคยบันทึกไว้มีวันที่ใน `Sessions.date` ถูกต้อง และ `Attendance.session_id` ชี้ไปยังคาบที่ถูกต้อง
- เวอร์ชันนี้ไม่เปลี่ยนวันของข้อมูลที่บันทึกไปแล้ว และไม่ย้าย Attendance เก่าโดยอัตโนมัติ หากข้อมูลใน Google Sheets เดิมผิดจริง ต้องตรวจ/แก้แต่ละแถวจากหลักฐานไฟล์ต้นฉบับก่อน

# AreWarin Tutor OS v2.0 — Botanical Minimal Pro

**UI/UX upgrade จาก v1.9** รองรับ GitHub Pages และ Google Sheets โดยรักษา schema และกลไก Ledger/การบันทึกเวลาเดิมไว้ (ยังไม่ได้เพิ่มระบบการเงิน/Portal/ระบบสิทธิ์หลายผู้ใช้)

## ฟีเจอร์ UI v2.0 ที่เพิ่มจริง

1. **Dashboard ใหม่**: แถบต้อนรับ, การ์ดสถิติ 4 ใบ, คาบสอนวันนี้ที่ลิงก์กับ Schedule, คอร์สที่ชั่วโมงใกล้หมด, ประวัติล่าสุด และปุ่มทำงานด่วน
2. **Sidebar แบบยุบ/ขยาย** บนคอมพิวเตอร์ เก็บสถานะบนอุปกรณ์นี้ และมีคำอธิบายเมื่อชี้ไอคอน
3. **Global Search**: กดไอคอนค้นหา หรือ `Ctrl+K` (`⌘K` บน Mac) ค้นหานักเรียน, คอร์สที่เปิด และกลุ่มเรียน; กดผลลัพธ์เพื่อไปหน้าที่เกี่ยวข้อง
4. **Topbar Quick Action**: ปุ่มลงเวลาในทุกหน้า
5. **Student Cards**: ปุ่มเปิดโปรไฟล์ขนาดใหญ่ และเมนู `···` สำหรับแก้ไข เพิ่มคอร์ส และต่อคอร์ส ช่วยลดปุ่มจำนวนมากบนการ์ด
6. **Import Progress**: แถบขั้นตอนอัปโหลด → ตรวจวันและเวลา → ตั้งค่าและจับคู่ชื่อ → ตรวจสรุปก่อนบันทึก เพื่อให้อ่านกระบวนการง่ายขึ้น โดยยังคงตารางสรุปและฟังก์ชัน Excel Import จาก v1.9
7. **Modal & Forms**: ปรับขนาดและแถบหัวข้อพร้อมพื้นที่เลื่อนสำหรับฟอร์มยาว บังคับใช้หน้า Final Review ก่อนหักชั่วโมงตามระบบเดิม
8. **Mobile Bottom Navigation**: ภาพรวม / ตาราง / ลงเวลา / Meet / เพิ่มเติม พร้อมรองรับ Safe Area
9. **Light/Dark Mode**: ปุ่ม ◐ บนแถบด้านบนและจำการตั้งค่าบนอุปกรณ์ (เป็นธีมทางเลือก อาจมีจุดที่ยังปรับคอนทราสต์เพิ่มได้)
10. **Responsive Design**: ปรับช่องไฟและอักษรให้อ่านง่ายบนจอคอมพิวเตอร์และมือถือ

## ไฟล์และวิธีอัปเดตจาก v1.9

1. สำรอง **Google Sheets** และไฟล์เว็บไซต์เดิม
2. แตก ZIP และอัปโหลด `index.html`, `assets/app.js`, `assets/style.css` ไปแทนไฟล์เดิมบน GitHub Pages
3. **เก็บ `config.js` เดิมไว้** หากเคยกำหนด Google OAuth Client ID และ Spreadsheet ID แล้ว; อย่านำไฟล์ตัวอย่างที่ว่างไปแทน
4. รอ GitHub Pages เผยแพร่ จากนั้นรีเฟรชแบบ Hard Reload (`Ctrl+Shift+R`)
5. ทดลองบันทึกข้อมูลนักเรียนทดสอบ 1 คาบ ตรวจยอดในหน้า Students และใน Google Sheets จริงก่อนใช้งานข้อมูลจริง

**ไม่มีการเปลี่ยน schema Google Sheets ใน v2.0:** ไม่ต้องรัน `Setup.gs` ซ้ำ หาก v1.9 ใช้ฐานข้อมูลชุดเดิมได้ครบแล้ว

## การตรวจสอบ

- ตรวจ syntax ของ `app.js`
- รัน unit/regression tests 6 ชุดที่มาจาก v1.9 ผ่าน
- ทดสอบ Chromium ทั้งหน้าจอ desktop 1440px และ mobile 390px: Dashboard, Search, Student Profile, Import, เมนูมือถือ, Sidebar, Theme
- ทดสอบ browser regression เดิม: Manual Record, Direct Deduction, Duplicate Protection, Cancellation & Refund, Excel multi-date simulation, Legacy Pending
- **ยังไม่ได้ทดสอบ Google Sheets จริง** และ OAuth ของบัญชีผู้ใช้; การทดสอบ Excel ในชุด automated เป็น simulation ตาม schema รายงาน ไม่ใช่การยืนยันทุก format ที่ Google Meet ส่งออก

## ข้อจำกัดเดิมที่ยังมี

- เขียนลง Google Sheets API จากเบราว์เซอร์โดยตรง ไม่รับประกัน transaction locking เมื่อติวเตอร์หลายคนบันทึกพร้อมกัน
- Google OAuth อาจต้องให้ผู้ใช้กดลงชื่อเข้าใช้อีกครั้งเมื่อสิทธิ์หมดอายุ; ไม่ควรเก็บ Client Secret หรือโทเคนถาวรใน GitHub Pages
- รายการ `pending` จากเวอร์ชันเก่ายังไม่ถูกหักโดยอัตโนมัติ; ต้องตรวจและอนุมัติรายการเก่าที่เมนูประวัติ
- UI Dark Mode เป็นฟีเจอร์เสริม; หากอุปกรณ์มีข้อจำกัดเรื่องคอนทราสต์ให้ใช้ Light Mode

# Legacy reference — v1.9 workflows

Web app บริหารนักเรียนและชั่วโมงเรียนแบบ GitHub Pages + Google Sheets API (Google Apps Script ใช้ตั้งค่าชีตเริ่มต้น) เน้นการบันทึกครั้งเดียวและตัดชั่วโมงทันที **หลังผู้ใช้ตรวจหน้า Final Review และยืนยัน**

## มีอะไรใหม่ใน v1.9

1. **Record Hours**: เลือกวันที่ เวลาเริ่ม–สิ้นสุด ระบบแสดงระยะเวลาเป็น `1 ชม. 30 นาที` อัตโนมัติ ไม่ต้องเลือกวิธีตัดชั่วโมงซ้ำอีก หลัง Final Review ระบบบันทึกคาบ + Attendance + Hour Ledger ในชุดเดียว
2. **Excel Import**: รองรับหลายไฟล์ อ่านวันที่จากข้อมูล Excel ก่อน (ถ้ามี) มิฉะนั้นอ่านจากชื่อไฟล์ แต่ละไฟล์เก็บวันที่แยกกัน ป้องกันไฟล์ซ้ำด้วย fingerprint และตรวจเวลาที่ทับซ้อนกันระหว่างนักเรียน/ไฟล์ เมื่อบันทึกสำเร็จจะตัดชั่วโมงทันที แล้วล้างพื้นที่อัปโหลดพร้อมใช้งานชุดใหม่
3. **Final Review**: แสดงวันที่แต่ละคาบ นักเรียน คอร์ส เวลาจริง เวลาที่จะหัก และยอดก่อน–หลัง จากนั้นให้ติ๊กรับรองก่อนกดยืนยัน **ไม่มี Pending สำหรับรายการใหม่**
4. **ยกเลิก/คืนชั่วโมง**: นักเรียนมีปุ่มยกเลิกรายการจาก Recent Attendance สามารถคืนชั่วโมงเฉพาะคนนั้นได้ หากยกเลิกคาบทั้งกลุ่มภายหลัง จะไม่คืนซ้ำให้คนที่ยกเลิกไปแล้ว ข้อมูลเก่าคงอยู่ใน Audit และ Ledger
5. **คาบเก่าที่ Pending**: ไม่ถูกตัดย้อนหลังเอง หน้า Dashboard จะแสดงคำเตือน ให้ไปเมนู “ประวัติและแก้ไข” เพื่อเลือกและยืนยันตัดรายการเก่าครั้งเดียว
6. **Class Schedule และวันเรียน**: แสดงทั้งคาบตามกำหนดและคาบที่บันทึกจริงจาก Record Hours / Excel มีมุมมองรายสัปดาห์/ตาราง; Dashboard แสดงรายชื่อที่สอน **วันนี้** จากตารางเรียน
7. **Student Profile**: แสดงวันเรียนที่กำหนดไว้และประวัติการเรียนที่บันทึกตามวันที่ พร้อมระยะเวลาแบบอ่านง่าย
8. **เพิ่ม/แก้ไขนักเรียน**: มีส่วน “กำหนดวันเรียน (ไม่บังคับ)” โดยระบุวันที่ เวลา ติวเตอร์ และรายสัปดาห์ แล้วเชื่อมกับ Class Schedule
9. **ลงคอร์สเพิ่ม**: จากโปรไฟล์สร้างคอร์สใหม่ หรือเลือกชื่อคอร์สที่มีอยู่เป็นต้นแบบ (สร้างยอดชั่วโมงแยกของนักเรียน) รองรับเลือกกลุ่มเรียนพร้อมเพิ่มสมาชิก
10. **Loading UX**: มีหน้าต่างโหลดเมื่ออ่าน Excel หรือบันทึกข้อมูล ผ่าน SweetAlert2 เมื่อโหลดได้ และ fallback ในระบบเมื่อ CDN ใช้ไม่ได้

## อัปเกรดจาก v1.7.1

1. **สำรอง Google Sheets และไฟล์เว็บก่อน** รวมถึง `config.js` เดิม
2. แตก ZIP แล้วนำ `index.html`, `assets/app.js`, `assets/style.css` ไปแทนบน GitHub Pages (ควรวางผ่าน Git commit เพื่อย้อนเวอร์ชันได้)
3. รักษา **`config.js` เดิม** ซึ่งมี Google OAuth Client ID และ Spreadsheet ID ของคุณ ไม่ต้องใช้ไฟล์ว่างใน ZIP ถ้าเคยตั้งค่าแล้ว
4. รอ GitHub Pages อัปเดต และรีเฟรชหน้าเว็บแบบ Hard Reload (`Ctrl + Shift + R`)
5. ทดลอง 1 คาบกับนักเรียนทดสอบ ตรวจว่าตาราง `Sessions`, `Attendance`, `Ledger` เพิ่มข้อมูลและยอดคงเหลือเปลี่ยนทันที

**ไม่ต้องรัน `Setup.gs` ใหม่** หากมาจาก v1.7.1 ที่ตั้งค่าสมบูรณ์ เพราะ v1.9 ไม่เพิ่มคอลัมน์/ชีตใหม่ ใช้ schema เดิมทั้งหมด

## ขั้นตอนบันทึกเวลา

**Manual:** Record Hours → วันที่+เวลา → นักเรียน/คอร์ส → ตรวจหน้าสรุป → ติ๊กถูก → “ยืนยันบันทึกและตัดชั่วโมง”

**Excel:** Import Excel → ลากหลายไฟล์ → ดูตารางวันที่/เวลาแต่ละไฟล์ → ตั้งค่าชั้นเรียน/แหล่งเวลาที่ต้องการ → จับคู่ชื่อ Meet → ตรวจหน้าสรุป → ติ๊กถูก → “ยืนยันบันทึกและตัดชั่วโมง” → หน้า Import เคลียร์พร้อมใช้ต่อ

ค่าเวลาในรายงานอาจต่างจากเวลาที่เลือกใช้หักได้ ตาราง Final Review แยก **เวลาจริง** กับ **เวลาที่หัก** และบันทึกตามแพ็กเกจของนักเรียนแต่ละคน

## วิธีจัดการข้อมูล Pending เดิม (สำคัญ)

ไฟล์ที่บันทึกไว้ก่อน v1.9 อาจมีสถานะ `pending` อยู่แล้ว และ **ยังไม่ได้หักชั่วโมง** อย่านำไฟล์นั้นมา Import ซ้ำ เพราะ fingerprint จะกันไว้ ให้ใช้เมนู **ประวัติและแก้ไข → เลือกรายการเก่าที่ยังไม่ตัด → สรุปก่อนยืนยัน → ตัดชั่วโมงรายการเก่า** ตรวจวันที่และยอดก่อนยืนยัน เพราะรายการที่เคยปรับยอดชั่วโมงด้วยมืออาจได้รับผลกระทบจากการตัดย้อนหลัง

## การยกเลิก Recent Attendance

กดเปิดโปรไฟล์นักเรียน → ประวัติการเรียนตามวันที่ → **ยกเลิกรายการ** ระบบยกเลิกอย่างปลอดภัยและคืนยอดที่เคยตัด โดยยังเก็บแถวประวัติไว้ ไม่ใช่ลบหลักฐานถาวร

**ป้องกันซ้ำ:** มีทั้งการตรวจ fingerprint สำหรับไฟล์เดิม และเช็กเวลาเข้าร่วมทับซ้อนในวันเดียวกันสำหรับนักเรียนเดียวกัน ทั้ง Manual และ Excel ภายในชุดเดียว / ข้อมูลที่โหลดมา ข้อจำกัด: หากหลายผู้ใช้บันทึกพร้อมกันจากหลายแท็บ/อุปกรณ์บน Google Sheets API แบบตรง อาจยังเกิด race condition ได้ ควรใช้ผู้ดูแลหนึ่งคนบันทึกต่อครั้ง หากต้องการบันทึกพร้อมกันหลายผู้ใช้อย่างปลอดภัยต้องย้ายธุรกรรมไป backend ที่มี locking/unique constraints

## โครงสร้างที่ใช้

- `index.html` เว็บหลัก
- `assets/app.js` งานประมวลผลและอินเทอร์เฟซ
- `assets/style.css` ธีม responsive
- `config.js` ตัวระบุ OAuth/Sheet **ว่างใน ZIP ตัวอย่าง**
- `apps-script/Setup.gs` ตั้งค่า Google Sheets เฉพาะติดตั้งครั้งแรก
- `samples/` ไฟล์ตัวอย่าง
- `tests/` Node smoke tests และ browser integration test

## ความปลอดภัยและข้อจำกัด

- **อย่าใส่ Client Secret, access token, รหัสผ่านลงใน GitHub Pages** และอย่า Publish Google Sheets เป็นสาธารณะ
- ต้องได้รับสิทธิ์ Google OAuth ในโปรเจกต์ที่ถูกต้อง; เมื่อโทเคนหมดอายุ อาจต้องลงชื่อเข้าใช้อีกครั้ง
- เอกสารตัวอย่างใช้ Demo mode เก็บข้อมูลในเบราว์เซอร์ ไม่ใช่ฐานข้อมูลจริง
- ตรวจโค้ดและทดสอบใน Chromium/Node ด้วยข้อมูลจำลองแล้ว แต่ **ยังไม่ได้ทดสอบกับ Google Sheets ของคุณโดยตรง** สำรองก่อนใช้งานจริงเสมอ
- ไม่รวมระบบ shared wallet กลุ่มแบบหักหนึ่งครั้งต่อแพ็กเกจกลางในรุ่นนี้ (หักตามแพ็กเกจรายนักเรียนตามที่เลือก)
